<objective>
Land the two database fixes that must precede the schema typing: the real `clearCacheData()` bug
(D-07, its own commit) and the v5 migration's directive-backed key deletion (D-08).

Purpose: `clearCacheData()` clears a store that the v12 migration deleted. idb opens a transaction
on the missing store inside an async function, so the call rejects with `NotFoundError`:
`relayScoreboardStats` is never cleared, `window.location.reload()` never runs, and the settings
button that calls it spins forever. D-05's typing (plan 06-09) would flag the line at compile time,
so it is fixed first, on its own, as the phase's single deliberate behavior change. D-08 removes a
directive with a destructure that produces the same stored object.

Output: one bug-fix commit and one type-only commit in `src/services/database/index.ts`.
</objective>
