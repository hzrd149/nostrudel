<objective>
Replace the webxdc iframe message's `any` cast with an `unknown` read narrowed by a tested type
guard, and type `useWebxdc`'s collected events as the `NostrEvent`s they are (D-11, D-14).

Purpose: `event.data` crosses a trust boundary (a sandboxed iframe running third-party app code).
Typing it as `any` hides that; typing it as `unknown` and narrowing makes the check explicit. D-15
forbids the guard from rejecting anything the old truthiness check accepted, and D-14 requires a
test because a wrong guard would silently drop messages.

Output: one new pure module and its test, and 4 bucket-E findings cleared.
</objective>
