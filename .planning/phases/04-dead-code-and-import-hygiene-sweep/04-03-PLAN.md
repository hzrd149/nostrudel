<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lint finding → deletion | The rule flags an unused *binding*, not an unused *expression*; deleting the statement can remove a live call |
| TypeScript → runtime | `tsc` proves references resolve; it cannot prove a removed subscription had no effect |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | the four dead functions and two constants | high | mitigate | Re-grep each symbol immediately before deleting and require the only hit to be the declaration; `pnpm build` after the task catches any reference `tsc` can see. A dynamic or string-keyed reference would evade both — accepted as residual and noted, since the lint rule itself would equally miss it. |
| T-04-10 | Tampering | deleting a live hook invocation along with its unused binding | high | mitigate | The three hook sites are handled individually in Task 2 with a named evidence requirement, not batch-deleted. `messages/index.tsx` carries an explicit correction: its `locked` binding is live and must survive. An underscore-prefix fallback is authorised where the executor is unsure. |
| T-04-11 | Tampering | deleting a `useState` tuple whose reader half is live | medium | mitigate | Only the setter slot is elided; `pnpm build` fails loudly if the reader is removed, so this one is fully typecheck-covered. |
| T-04-09 | Repudiation | inherited hook-order error in `messages/group/index.tsx` | medium | accept | Backlog 999.2 / D-15; enumerated by 04-11, not fixed here. |
