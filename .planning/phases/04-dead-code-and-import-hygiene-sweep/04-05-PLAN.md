**Task 1 — `src/components/markdown/markdown.tsx` carries 10 of the 39**, all a `node` parameter
destructured from react-markdown's component contract at lines 42, 49, 56, 63, 70, 77, 85, 113, 120
and 130.

There is a trap here worth stating plainly: these signatures destructure `node` alongside a
`...props` rest element, so simply removing `node` from the destructuring does not delete it — it
makes it fall into `...props`, which is then spread onto a Chakra component and forwarded to the
DOM. That turns a lint warning into a React unknown-attribute warning at runtime. Rename in place
instead, keeping the property bound and prefixed.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| function signature → caller | Deleting a positional parameter silently changes what later arguments bind to |
| destructured prop → rest spread | A property removed from a destructuring does not disappear; it flows into `...props` and onto the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-22 | Tampering | deleting a contract-bound parameter and shifting later positional arguments | high | mitigate | The contract-bound test is applied per site, with event handlers, callbacks, refs and interface implementations named as prefix-only. Call sites are grepped before any deletion, and `pnpm build` type-checks every remaining caller. |
| T-04-23 | Tampering | dropping `node` from a markdown destructuring so it is forwarded to the DOM | medium | mitigate | Task 1 forbids dropping the property where a rest spread exists and requires an in-place rename; the summary must report the renamed-versus-dropped split. |
| T-04-24 | Tampering | diverging remedies for a parameter shared by two components | medium | mitigate | `hideDrawerButton` is named explicitly; the shared type must be checked and the same remedy applied to both files. |
| T-04-SC | Tampering | npm/pip/cargo installs | low | accept | No packages installed. |
</threat_model>
