tier-three wave alongside the other big split.

New modules under `src/services/wallets/`:

  backend interface, and the type label record. Six or more files already import these as types.
- **`webln.ts`** — the browser-provider interface, the availability check, the provider getter and
  the WebLN backend factory.

  routines, the connect-wallet reconciliation, and the twenty-one-member public API.

balance-increase waiter — land in exactly one module each (see Task 1).

`src/services/wallets.ts` ceases to exist as a file.

and the backend factories move as they are. Resist replacing the existing runtime backend selection

Commit the relocation as move-only commits per D-16. If a move cannot be pure because an import
