  <action>
Add exactly one file-level ignore directive naming `code-quality/duplicate-block` to each of these
four files, as the first line of each file, above its existing imports.

Use file scope rather than line scope here. Each of these four anchor lines sits in a JSX
attribute list or a JSX children position where a line comment is either syntactically invalid or
fragile to place, and the Phase 3 probe already found line-scoped placement finicky. File scope is
exactly scoped in this case because each of these four files carries exactly one duplicate-block
finding, so the directive suppresses that finding and nothing else. This follows the same
reasoning D-06 applies to the torrent taxonomy. If a rescan shows a file-level directive would
suppress a second duplicate-block finding in the same file, stop and use a line-scoped directive
instead — over-suppression is not acceptable.

Each reason must explain why the code could not be factored rather than asserting the duplication
is tolerable. Per D-05 the shared substance for these four is coincidental shape rather than
shared meaning:

- For the code and youtube renderers: both wrap the same embed container, but the hosts, aspect
  ratios, embed URL construction and permitted iframe features differ, so a shared abstraction
  would take more configuration parameters than it removes duplicated lines. D-05 considered and
  rejected a shared embed component; the Deferred Ideas list says revisit only if a third embed
  type appears.
- For the groups view: the matched spans are two arms of a ternary chain that render the same grid
  container over different data sources with different loading and empty states; factoring them
  would merge two independently-evolving branches behind a flag.
- For the list history modal: the matched spans are the trailing badge and button group of two
  sibling row variants, one of which additionally renders an unlock control; the tails are similar
  because the row variants are siblings, not because they share a behaviour.

Reword each reason in your own terms — the exact wording is yours per Claude's Discretion — but
every one must answer "why couldn't you fix it instead". A reason of "out of scope" or "less bad
than the others" fails the bar and must not be written.
