structure.

render the same third-party autocomplete element with the same loading component, the same minimum

element type.

  the input variant and do not remove the existing one — that asymmetry is pre-existing and
  changing it is out of scope.

  escape hatches is Phase 6's scope; touching them here would pull a different bucket into this

The factory is internal — do not export it.

percentage — so the formatting differs per slider and belongs at the call site, not inside the
shared component. Getting this wrong would either change the displayed text or force a format-mode
flag into the component, both of which are worse than passing the finished label.

Keep the component colocated in this same file and do not export it. A three-use-site pattern does
not warrant a new shared component file; the in-repo convention is an internal PascalCase helper
beside its call sites. Leave the surrounding grid, the voice selection control above it and the
