<objective>
Remove the wrong ARIA from the two composite widgets (D-16 wave 1): the relay URL input's
hand-added combobox attributes and redundant listbox/option roles (D-10), and the option role on
the composer autocomplete items (D-11).

Purpose: a native `<input list>` plus `<datalist>` already exposes combobox and listbox semantics;
the partial override claimed an expanded state the browser does not drive and lacked
`aria-controls`. react-textarea-autocomplete owns the surrounding `ul > li > div[role=button]`
markup, so an option nested inside it is invalid ARIA. Both are user-noticeable for assistive
technology, so each lands in its own `fix(07-03)` commit (D-17).

Output: 11 bucket-F findings cleared (rows 7-17 of 07-BASELINE.md), no ignores.
</objective>
