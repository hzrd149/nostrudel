<objective>
Install the aislop scanner as an exact-pinned devDependency behind a blocking package-legitimacy checkpoint, and add the two lint scripts that every later plan and the CI workflow call.

Purpose: D-14 requires local runs and CI to use the identical aislop binary so a new release cannot silently shift scores or invalidate the D-02 calibration. D-15 fixes the exact script strings, and `lint:ci` is the D-01 changed-files-only gate. RESEARCH.md's Package Legitimacy Audit tagged `aislop` as [SUS] (a too-new heuristic false positive), so protocol requires a blocking human legitimacy check before any install; that checkpoint is never auto-approvable.

Output: `package.json` (aislop `0.16.1` devDependency, `lint` and `lint:ci` scripts) and the matching `pnpm-lock.yaml` update. No changeset: this is tooling-only and nothing user-facing ships.
</objective>
