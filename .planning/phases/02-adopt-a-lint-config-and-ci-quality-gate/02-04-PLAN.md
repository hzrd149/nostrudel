<objective>
Install aislop's Claude Code hook at project scope in feedback mode, pinned to the local devDependency, after the maintainer decides which generated agent-instruction files to commit.

Purpose: D-16 gives coding agents per-edit lint feedback while keeping CI as the only enforcement point. Research found the installer writes two files D-16 did not anticipate: `.claude/AISLOP.md`, and a new `.claude/CLAUDE.md` that Claude Code auto-loads as project memory. That changes what every agent session reads in a repo whose guide is AGENTS.md, so it needs an explicit maintainer choice. D-14 requires the committed hook command to use the same pinned binary as local scripts and CI.

Output: new `.claude/settings.json`, plus `.claude/AISLOP.md` and `.claude/CLAUDE.md` only if the maintainer selects `keep-generated`.
</objective>
