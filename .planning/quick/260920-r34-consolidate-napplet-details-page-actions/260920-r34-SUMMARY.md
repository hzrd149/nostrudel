# Quick Task 260920-r34: Consolidate napplet detail page actions Summary

**Replaced the napplet detail page's three-icon header action group with a reusable `NappletMenu` (Share Link, Copy app address, Quote Event, View Raw) and deleted the page's Details section along with its dead code.**

## Accomplishments
- New `src/components/napplets/napplet-menu.tsx` — a standalone `NappletMenu` component that takes a `NostrEvent` plus `IconButtonProps`, imports nothing from `src/views`, and composes `ShareLinkMenuItem`, a copy-NIP-19-address item, `QuoteEventMenuItem`, and `DebugEventMenuItem` behind `DotsMenuButton`
- `store-detail.tsx`'s header `actions` prop now renders a single `NappletMenu` instead of the `ButtonGroup` of `DebugEventButton`/`EventShareButton`/`EventQuoteButton`
- Deleted the "Details" section (kind, manifest pointer naddr, author link), the `DetailRow` helper it alone used, and the three imports (`Code`, `Link`, `ReactNode`) that only that section kept alive; unwrapped the now-single-child `SimpleGrid` so "Supported intents" is a direct child of the page's outer column
- Added `.changeset/brave-napplets-share.md` describing the user-facing change as a patch bump
