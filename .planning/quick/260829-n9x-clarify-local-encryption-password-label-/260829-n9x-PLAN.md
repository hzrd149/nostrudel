<objective>
Close GitHub issue hzrd149/nostrudel#356: the signin-flow password prompt shown after a user
pastes a raw `nsec` reads as though the password already exists, when in fact the user is
inventing it on the spot to encrypt the key in this browser's local storage.

Reword that one prompt so it unambiguously signals "you are creating this now, it is local-only",
and sharpen the sibling `ncryptsec` prompt on the same screen so the create-vs-enter contrast is
legible at a glance.

Purpose: remove momentary confusion at the exact moment a user is handling their raw secret key.
Output: a copy-only diff in `src/views/signin/nsec.tsx`. No crypto, control-flow, or account-type
changes.
</objective>
